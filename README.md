# 🎮 AR Algorithm Catching Game

เกมคำนวณอัลกอริธึมแบบ AR (Augmented Reality) ที่ใช้ตรวจจับมือผ่านกล้องเว็บแคม

## 📖 วิธีเล่น

1. **เปิดกล้องเว็บแคม** - อนุญาตให้เข้าถึงกล้องของคุณ
2. **ยื่นนิ้วชี้** ไปแตะวัตถุที่ตกลงมาจากบน
3. **แตะสีเขียว** (Algorithm) ได้ **+10 คะแนน** ✅
4. **แตะสีแดง** (ไม่ใช่ Algorithm) โดน **-5 คะแนน** ❌

## 🎯 เป้าหมาย

ทำการเลือกเฉพาะวัตถุที่เกี่ยวข้องกับขั้นตอนของอัลกอริธึมให้ได้แต่ละอย่าง

### ✅ Algorithm (สีเขียว)
- เริ่มทำงาน (Start)
- รับค่าข้อมูล (Input)
- คำนวณผล (Process)
- ตรวจสอบเงื่อนไข (If/Else)
- ทำซ้ำ (Loop)
- แสดงผลลัพธ์ (Output)

### ❌ ไม่ใช่ Algorithm (สีแดง)
- นอนกลางวัน
- นั่งสมาธิ
- กินหมูกระทะ
- ลืมรหัสผ่าน
- คุยโทรศัพท์

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5 Canvas** - สำหรับวาดกราฟิก
- **MediaPipe Hands** - สำหรับตรวจจับมือ AI
- **JavaScript** - ลอจิกเกม
- **WebCamera API** - เข้าถึงกล้องเว็บแคม

## 🎨 การปรับแต่ง

### เปลี่ยนความเร็วของวัตถุ
แก้ไขบรรทัดนี้ในไฟล์ `index.html`:
```javascript
speed: Math.random() * 3 + 3,  // เปลี่ยนค่า 3 เป็นค่าที่ต้องการ
```

### เพิ่มคะแนนของรายการ
แก้ไขในส่วน updateGame():
```javascript
if (item.isAlgo) {
    score += 10;  // เปลี่ยนค่า 10 เป็นค่าที่ต้องการ
}
```
